Markdown, HTML, images, PDFs, CSVs and Mermaid diagrams preview beside the chat and update as the agent rewrites them. Files open in tabs, and you can edit the source.

Checks, reviews and threads, with what blocks the merge at the top. Send a failing check to the agent in one click, then merge from the same tab.

Your issues and sprints as a task list. Start work opens a chat in a worktree, a separate checkout on its own branch, named after the issue.

A terminal under each chat, run by a small background service. Quit Nushi and the test run keeps going.

Answer from your phone.

Follow chats and answer an agent's questions from your phone. It connects through a relay, a small server you run yourself, and everything it sends is end-to-end encrypted.
